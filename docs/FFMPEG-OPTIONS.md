# FFGrabber user guide — advanced FFmpeg options

## Built-in controls

The standard fields build common transcode, stream-copy/remux, audio-extraction and video-only commands. The command preview shows the generated argument vector before you start a job.

## Advanced option groups

Expand **Advanced FFmpeg options** to supply ordinary FFmpeg flags:

- **Global / logging:** options such as `-loglevel verbose`, `-report` or `-stats_period 1`.
- **Input / demuxer:** inserted before `-i`; examples include `-f mov`, `-ss 00:00:10`, `-probesize 50M` and `-analyzeduration 100M`.
- **Stream mapping / selection:** examples include `-map 0:v:0 -map 0:a?`, `-map_metadata 0` and `-map_chapters 0`.
- **Video encoder:** encoder AVOptions such as `-profile:v high`, `-level:v 5.1`, `-tune film`, `-x264-params ...` or `-x265-params ...`.
- **Audio encoder:** codec-dependent AVOptions such as compression level, application mode, channel layout, or sample settings.
- **Filters / filtergraph:** use complete flags such as `-vf "scale=1920:-2"` or `-filter_complex "[0:v]scale=1920:-2[v]"`.
- **Muxer / container:** format-specific options such as `-f matroska`, `-movflags +faststart` or `-cluster_time_limit 1000`.
- **Other output:** output options such as `-shortest`, `-t 00:10:00`, `-metadata comment="created with FFGrabber"` and codec/muxer flags not covered above.

Quote values containing spaces. These fields are passed as individual process arguments; they do not run in a shell. FFmpeg's option semantics are order- and context-dependent. Options are emitted in the order displayed in the preview. When the same option is generated by the standard fields and entered in an advanced field, the later value normally takes precedence, but some options accumulate or have codec-specific behavior.

## FFmpeg option browser

Use **FFmpeg options & capabilities…** to load the full generic option help and the installed tool's encoder, decoder, codec, format, muxer, demuxer, filter, bitstream-filter, protocol, device, hardware-acceleration, pixel-format, sample-format and channel-layout lists. To inspect a specific component, use **Show detailed help** with topics such as `encoder=libx265`, `decoder=h264`, `muxer=matroska`, `demuxer=mov`, `filter=scale`, or `protocol=https`. These results come from the FFmpeg executable actually installed, not a copied static catalogue.

Some switches appear only when a component was compiled into FFmpeg. Hardware encoding additionally requires a supported GPU, driver and backend. The GPL static release build is feature-rich but cannot include absolutely every third-party or legally restricted codec.

## Full log export

Open **Options… → Save Logs…** and choose where the ZIP should be written. The support ZIP includes the complete current session log (not the abbreviated on-screen preview), historical FFGrabber session logs found in the local log folder, OS/runtime details, current setting values, queue snapshot, FFmpeg/ffprobe/ffplay versions, FFmpeg build configuration, and full help/capability reports supported by the installed binaries. It does not include the contents of source media. Review the bundle for local paths or sensitive command-line options before sharing it.

Session logs are stored under `%LOCALAPPDATA%\FFGrabber\Logs`.
