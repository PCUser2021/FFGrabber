# FFGrabber 0.5.0

## UI and FFmpeg option browser

- Add a translucent acrylic/Mica-capable window surface with a dark glass-panel design and improved contrast.
- Improve primary workflow buttons with native Windows glyph icons.
- Expose basic help, advanced tool help, and the complete -h full option catalogue from the user-imported FFmpeg executable.
- Add live search, clipboard copy, and UTF-8 text export for FFmpeg help output.
- Provide a direct link to the official FFmpeg command-line documentation from Options.
- Preserve the import-only architecture: FFmpeg, ffprobe and ffplay are never bundled or downloaded by FFGrabber.
