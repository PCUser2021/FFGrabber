# Preserved Dropbox capture/hardware guides

These six text files are verbatim UTF-8 snapshots of the capture and hardware-reference files currently available through the user's Dropbox connection: DirectShow.txt, HWAccelIntro.txt, Capture_ALSA.txt, Capture_Desktop.txt, Capture_Webcam.txt and Capture_Lightning.txt.

They are research inputs for the in-app searchable option index, capture starter profiles and documentation. The notes contain platform-specific Linux/macOS examples, historical APIs, build-time configure flags and examples involving external utilities. Those examples are not represented as universal Windows runtime settings. The current imported FFmpeg's own help and capability lists remain authoritative.

The previous release's 14 encoder guide profiles and option index remain integrated in FFGrabber, but their raw source objects are not accessible from the current Dropbox reference set; this directory makes no claim to contain copies of those 14 files. The six files in this directory are preserved without editorial changes.
