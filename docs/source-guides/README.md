# Preserved Dropbox capture/hardware guides

These six text files are preserved UTF-8 snapshots of the capture and hardware-reference files available through the user's Dropbox connection: DirectShow.txt, HWAccelIntro.txt, Capture_ALSA.txt, Capture_Desktop.txt, Capture_Webcam.txt and Capture_Lightning.txt.

They are research inputs for the in-app searchable option index, capture starter profiles and documentation. The notes contain platform-specific Linux/macOS examples, historical APIs, build-time configure flags and examples involving external utilities. Those examples are not represented as universal Windows runtime settings. The current imported FFmpeg's own help and capability lists remain authoritative.

The 14 lower-case `*_guide` / profile files in this directory are reconstructed profile summaries supplied for FFGrabber recovery. They preserve the provided recommended flags, stage and description, but they are not verbatim copies of the historical full encoder documents listed by `EncodingGuideOptionIndex.cs`. The index's original source filenames and descriptions remain intact. The six capture/hardware reference files above are preserved separately from these reconstructed profiles.
